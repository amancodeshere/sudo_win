# sudo_win

UNSW Battlecode bot in C++20. Start with [the bot README](algo_bot/README.md)
for build, sandbox benchmarks, and submission packaging.

The stable strategy uses remembered-map routing, body-aware survival search,
confirmed own-body memory, cached enemy move prediction, cautious portal escapes, short pearl sprints, and
champion-preserving rescue splits and resource coordination for small collectors.
Population expansion, longer sprint forecasts and sealed-pocket priority remain
experimental. Read [the latest 85-game review](algo_bot/REPLAY_V3_REVIEW.md),
[the earlier strategy review](algo_bot/STRATEGY_UPDATES.md),
[the 75-game replay audit](algo_bot/REPLAY_AUDIT.md),
[validation results](algo_bot/VALIDATION.md), and the
[implementation roadmap](algo_bot/IMPLEMENTATION_GUIDE.md).
